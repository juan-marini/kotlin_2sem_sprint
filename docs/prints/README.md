# Prints do EducaMais

Evidências do app rodando no emulador (critério de Evidências da rubrica).
Nesta Sprint não é exigido vídeo — prints bastam.

Salve os arquivos nesta pasta com os nomes abaixo, um print por tela
principal do fluxo:

| Arquivo | Tela |
|---|---|
| `01_login.png` | Login, com o fundo em gradiente e a marca |
| `02_login_erro_validacao.png` | Login com os campos vazios, mostrando as mensagens de erro |
| `03_home_inicio.png` | Aba Início: saudação, indicadores, alerta preditivo em destaque |
| `04_home_cursos.png` | Aba Cursos: busca, chips de categoria e lista |
| `05_detalhe_curso.png` | Detalhe de um curso com os módulos expandidos |
| `06_home_salas.png` | Aba Salas de Estudo, com uma sala ao vivo e uma lotada visíveis |
| `07_detalhe_sala.png` | Detalhe de uma sala de estudo |
| `08_chat_edia.png` | Chat da EdIA com uma resposta e o bloco de fonte visível |
| `09_perfil.png` | Perfil, com XP, indicadores e conquistas (uma bloqueada) |
| `10_sobre.png` | Tela Sobre, com os quatro pilares |

Print da árvore de commits do GitHub (histórico distribuído ao longo do
tempo) também é bem-vindo, mas não é obrigatório.
